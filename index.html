Binary puzzle rules

Every row and column follows three rules.

  1. They contain the same number of zeroes and ones.
  2. No more than two identical numbers can sit beside each other.
  3. No two completed rows or columns may be identical.
  1. Every row contains each number from 1 through 9 exactly once.
  2. Every column contains each number from 1 through 9 exactly once.
  3. Every outlined 3 × 3 box contains each number exactly once.
